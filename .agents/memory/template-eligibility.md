---
name: Template eligibility and compatibility
description: Why reusable manufacturer templates have multiple eligible categories but conservative page-layout matching
---

A single manufacturer template can cover multiple eligible quote categories, especially Interior Doors and Exterior Doors. Keep the quote's category assignment separate from template eligibility.

**Why:** The user explicitly needs shared door layouts across categories, without applying a template to unrelated products. Sharing one template avoids independently maintained copies that drift.

**How to apply:** Preserve manufacturer/category overlap conflict checks when extending template management. A layout match only prefills redactions; it is not proof that private content was removed. Human review remains mandatory, and template changes must never rewrite previously published or signed documents.
